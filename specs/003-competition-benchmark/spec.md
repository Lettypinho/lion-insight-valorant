# SPEC 003 — Benchmark da Competição

## Objetivo
Usar a base completa tratada e seus recortes opcionais para contextualizar o desempenho de uma equipe.

## Requisitos
- RF-001 — calcular referência com os outros times do recorte atual; sem filtros, usar a base completa.
- RF-002 — usar exatamente a mesma definição de métrica da equipe.
- RF-003 — exibir tamanho da amostra.
- RF-004 — calcular diferença em pontos percentuais.
- RF-005 — permitir filtros contextuais quando implementados.

## Regra
Para taxas, priorizar agregação por oportunidades válidas e não média simples das porcentagens das equipes.
